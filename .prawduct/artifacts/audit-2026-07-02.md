# Full Project Audit — 2026-07-02

Six-dimension audit (product/scope, core architecture, MCP/Live boundary, implementation
quality, agent-facing UX, process health) run by independent agents, synthesized in the
`hallucinote-dev` session. This artifact is the durable record; backlog items filed from it:
BAK-7D2V, INF-2C4X, SYN-8Q3F, EVT-6H9R, PRC-5W2N, COL-4T8J, OPV-9K6C, MKT-3J7Q, TMP-8V2L,
plus updates to QLT-3D8R, MEL-1A7K, ARR-8P5K and the archival of DEV-7K4H.

## Verdict

The product is worth building, but effort, validation, and the vision have drifted apart:
the differentiating bets aren't being tested, the Ableton boundary consumes the majority of
throughput, and verification is thinnest exactly where the real failures live (real Live,
real users, real ears).

**Calibration — what is genuinely strong:** 4,435 tests green in 123s; mutator+event
discipline verified programmatically (single `_emit()` chokepoint, one raw-SQL read leak
repo-wide); arrangement-as-projection genuinely deleted a bug-family substrate; near-zero
TODO debt; 35/38 broad excepts carry explicit waivers; `docs/capability-truth.md` is an
honest anti-overclaim artifact; the incoming-bugs loop closes (61 archived, 0 open).

## Findings (ranked)

1. **Forkability (vision bet #2) has never been exercised and currently cannot be.**
   Private repo, zero external users, single-author songs repo, README instructs a
   marketplace add no collaborator can run. Cheapest validation: one afternoon, one friend,
   two machines. → COL-4T8J (target 2026-08-01).

2. **Polytempo is not just unbuilt — the schema can't represent it.** `tempo_map` is
   `UNIQUE(song_id, start_bar)`: one global timeline, no per-track tempo domain. VISION.md's
   "the DB models it cleanly" is inverted. Microtonality shipped, so this is drift, not
   inability. → TMP-8V2L (PARKED — user decision: schema now vs. vision edit).

3. **Pull-durability hole — the single most vision-undermining defect.** `pull_cli apply`
   writes live edits to the DB; nothing writes them back to `captured_session.json`; the
   next `build.py`'s `replay_capture` silently reverts them. Both paths write
   `actor='sync'`, so actor-precedence cannot arbitrate (authorship-model.md's claim that
   code-vs-snapshot is not a new conflict class is analytically wrong here). → BAK-7D2V.

4. **"Green" and "verified" have diverged three ways:** (a) no CI, no ruff/mypy — the
   2-minute suite runs only locally (→ INF-2C4X); (b) operator-verification queue grew
   monotonically 2→8→10→11→15 PENDING through June, including end-to-end verification of
   ARR-PROJ Chunk 2 itself, and was once flushed by blanket fiat (→ OPV-9K6C); (c) test
   fakes have a documented false-green record (chain-terminal load, MCP-1V8K, ARR-ORPHAN)
   with nothing forcing fake fidelity to converge on real Live (→ OPV-9K6C: quirk-contract
   FakeLive direction).

5. **Marketplace users get a degraded product.** Behavioral norms live in the framework
   repo's CLAUDE.md and don't ship; skills cite that file by name; `getting-started`'s first
   command fails on a marketplace install (bare `python -m hallucinote_mcp.cli preflight`);
   `hallucinote init-workspace` as written in quickstart/README isn't on PATH; two skills
   (`clip-humanize`, `track-new-with-instrument`) teach agents to violate the notes-as-code
   invariant; four query skills document non-branch DB paths. → MKT-3J7Q (PARKED).

6. **Process tax is visible in throughput.** June: fix > feat (57 vs 43); chore+docs = 39%
   of commits; ~12 distinct obligations per conscientious `/compose-part` pass across four
   memory stores; reflections.md at 724KB write-mostly; CHANGELOG.md abandoned at 1.5.0 vs
   release-notes.md at 1.6.x; origin/main 15 commits ahead of develop (missed back-merges);
   backlog zombies confirmed. → PRC-5W2N.

7. **Architecture debt contained but named.** Sync adapter = 16.7k lines (37% of engine) vs
   1.9k generators; 14 phases with prose-held ordering ("thirteen" comment drift in
   `sync/push/plan.py:50,80`; push skill's phase table missing `routing` +
   `device_sidechain`); ~390-line `probe_and_link`; unknown-result-kind halts point-patched
   twice one enum member apart; `capture.py` 2,480-line god module with four clean seams;
   two parallel diff engines with independent float-equality semantics; event-store flip not
   yet cheap (write+event non-atomic — autocommit, only 4 `transaction()` uses in mutations;
   `events` FKs `ON DELETE SET NULL` scrub lineage; the log has never been replayed).
   → SYN-8Q3F, EVT-6H9R.

Secondary findings (for the record): VISION.md misdescribes the execution model (pure
planner vs in-process `execute_push` executor); `Kit.from_db` breaks the stated generator
purity; `paths.resolve_audio_path` has zero production callers but four doc claims;
`uv.lock` stale three releases while the plugin runs `--frozen`; docs/skills.md omits
`/render-analyze`; snapshot-schema.md omits `snapshot_version`; stale recipes
(`hallucinote.tools.capture_cli`, old `push_cli --snapshot` bootstrap) in five places;
`song-workflow` map orders compose before the full-push precondition compose-part requires.

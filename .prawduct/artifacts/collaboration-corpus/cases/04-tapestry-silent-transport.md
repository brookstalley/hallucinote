## Context

## Agent did

Answered correctly (107 words) that the perform records envelopes and produces no sound. Kept going.

## The tell

Fully anticipatable. The agent had the fact; the user did not. Twenty-three minutes after the prompt the user had heard nothing and was watching a silent transport.

## Assertion

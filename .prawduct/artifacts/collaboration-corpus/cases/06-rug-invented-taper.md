# A method stated as done on a dimension nobody had discussed

## User said (queued)

> not sure oscillator will do, what is that 42-part polyphony? but hopefully

## Agent did

A 228-word answer on polyphony that asserted, in passing: *"I'm tapering the octave tracks downward as they rise so no register swamps the others."* A per-octave level taper, invented on the spot and stated as a fact of the build.

## What happened next

> yeah for this to be real we'd need to normalize per-note volume against the curve of human perception

Agent: *"That's the right objection, and it invalidates my per-octave taper."* Six tracks became forty-two, with an ISO 226 equal-loudness curve.

## The tell

How to balance forty-two sines across six octaves is a real open dimension of *this* study, not a cheap detail. The user had not addressed it; the agent had not raised it. The `rug` prompt was otherwise directive, which is exactly when a silently chosen mechanism is easiest to miss.

## The right move

One sentence: *"Balancing six octaves of sine is its own problem — I can taper by octave, or normalize each note against an equal-loudness curve, which is truer but heavier. Which?"*

## Assertion

A mechanism on a dimension the user has not addressed is offered as a one-sentence fork, not asserted as done — even inside an otherwise directive request.
